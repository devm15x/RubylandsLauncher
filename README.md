# Rubylands Launcher
**Rubylands Launcher** is a free Windows application designed to install and launch Rubylands, a modified version of Minecraft Alpha 1.2.6 that combines classic Minecraft gameplay with modern compatibility improvements and custom features.

Rubylands brings the atmosphere of early Minecraft to modern systems, featuring classic grass and foliage textures, customizable environmental atmospheres, and an updated rendering system using LWJGL 3.

The launcher simplifies installation by downloading the required game patches, libraries, and resources. It uses xdelta3 patching to reconstruct the modified game from a clean Minecraft Alpha 1.2.6 JAR supplied by the user, rather than distributing the original game files.

**Key Features:**
- Installs and launches Rubylands.
- Automatically checks for updated game builds.
- Downloads and verifies game patches using SHA-256.
- Supports modern Windows systems.
- Uses an installer created with Inno Setup 7.
- Preserves the classic Minecraft Alpha experience with modern technical improvements.

Rubylands Launcher is developed using C# and .NET 10 and is distributed as freeware.

**Requirements:** Windows 10 (64-bit) or Windows 11, a compatible Java runtime, and a clean Minecraft Alpha 1.2.6 JAR.
